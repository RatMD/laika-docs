# &lt;PageContent /&gt;

**Renders the server-generated content of the current OctoberCMS page.**

The `<PageContent />` component reads `page.content` from the reactive LAIKA payload and places it
inside a `<div>`. It updates automatically when navigation replaces the active page.

> [!WARNING]
> Page content is inserted using `innerHTML`. It should only contain markup generated by your
> trusted OctoberCMS application.

## Basic Usage

`<PageContent />` is typically placed in a shared layout where the current page should appear.

```vue
<template>
    <main>
        <PageContent />
    </main>
</template>

<script lang="ts" setup>
import { PageContent } from '@ratmd/laika';
</script>
```

The component does not accept properties or provide slots. When the payload contains no page
content, it renders an empty `<div>`.
